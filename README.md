# 基于 MiMo-V2.5 的多Agent智能代码生成与审查系统

## 🎯 项目目标
构建一套全自动的代码审查与重构Agent系统，通过长链路多Agent协作，将代码规范评估效率提升80%，减少60%的初级代码审查工作量。同时支持根据需求描述自动生成高质量业务代码，并附带单元测试。

## 🧠 技术架构
- **监听Agent**：自动捕获Git仓库的Pull Request事件
- **分析Agent**：调用 MiMo-V2.5 进行代码深度分析（规范、安全、性能）
- **决策Agent**：判断问题类型，自动生成修复commit或风险提示
- **重构Agent**：对高复杂度代码自动生成重构方案和测试用例
- **生成Agent**：接收自然语言需求，生成符合团队规范的代码骨架
- **验证Agent**：自动运行测试，确保改动安全

## 📊 预期规模
- **日消耗Token**：~500万
- **应用团队**：20人后端开发团队
- **覆盖代码库**：超过50万行核心业务代码
- **预期调用频次**：每日触发24次全流程任务

## 🔧 技术栈
- Python, GitPython, FastAPI
- 大模型：MiMo-V2.5 系列
- Agent框架：OpenClaw / AutoGen
- CI/CD 集成：GitHub Actions
